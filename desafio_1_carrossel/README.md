# desafio_1_carrossel — Galeria inteligente de imagens

Aplicativo Flutter do Desafio 1 (carrossel): coleção de imagens navegável,
indicador da imagem atual e tela de detalhe com informações associadas.

## Documentação

Leia o guia completo (arquitetura, navegação, listas, imagens, carrossel,
parâmetros, estado e versão com assets) em
[docs/galeria-inteligente.md](docs/galeria-inteligente.md).

## Executar

```bash
flutter pub get
flutter run
```

## Estrutura

```text
lib/
├── main.dart
├── models/gallery_image.dart
├── data/gallery_data.dart
├── screens/
│   ├── gallery_carousel_screen.dart
│   └── image_detail_screen.dart
└── widgets/carousel_widgets.dart
```
